# タイピングクイズ

数学・物理・化学・情報・一般常識・雑学の一問一答を、ローマ字タイピングで答えるブラウザゲームです。

**プレイ:** https://lumiere2110.github.io/typing-quiz/

## 主な機能

- **ホーム画面**：プレイ / 問題一覧 / 遊び方
- **ルール設定**
  - 出題形式：タイピング（答えを見ながら入力）／クイズ（答えを隠して入力、ヒントあり）
  - 制限時間、1問あたりの回答時間、間違えていい回数、1問あたりの誤タイプ上限、問題数
  - カテゴリ・ジャンルの複数選択、問題の難しさ（易・普・難）、文字数（短・中・長）
  - **カスタムモード**：★お気に入り・⚠苦手リスト・正答率の低い問題から出題
- **プレイ中**：Esc でスキップ（不正解扱い）。shi/si・tsu/tu・n/nn など複数のローマ字表記に対応
- **リザルト**：出題された問題と答え、時間内の回答数、正答率、タイプ速度（打/分）、誤タイプ数、正確率など
- **問題一覧**：五十音順・カテゴリ順・難易度順・出題回数順・正答率順の並べ替え、カテゴリ/ジャンル絞り込み、検索、出題回数と正解数の表示

記録と設定はブラウザの localStorage に保存されます。

## 問題の追加

`js/data.js` の `QUESTION_DATA` に `[ジャンル, 難易度, 問題文, 答え, 読み]` の形式で追加してください。読みはひらがな（英字・数字はそのまま半角小文字）で書きます。
